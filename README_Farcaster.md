# AutoShout - Farcaster Mini App Deployment Guide

## Overview

AutoShout is a Farcaster Mini App that enables users to schedule and automatically publish Farcaster casts at their desired date and time. This guide covers the complete deployment process for the Farcaster Developer Portal and Base network integration.

## Prerequisites

- Node.js 18+ and npm/pnpm installed
- Farcaster Developer Portal account
- Base network wallet with ETH for contract deployment
- Access to Warpcast Mini App developer tools
